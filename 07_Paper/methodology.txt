# Methodology

## Dataset

The Banknote Authentication dataset was used in this study. It contains 1,372 observations and four numerical input features: variance, skewness, curtosis, and entropy. The target variable represents the banknote class, distinguishing genuine from forged banknotes.

## Data Preparation

The dataset was loaded and examined to understand its structure and variables. The original dataset contained no missing values. The four numerical features were used as input variables, and the class column was used as the target variable.

The dataset was divided into training and testing sets using an 80:20 split. Stratified sampling was applied to preserve the class distribution in both sets. The split used a fixed random state of 42, resulting in 1,097 training observations and 275 testing observations.

## Machine Learning Models

Three classification algorithms were evaluated:

1. Logistic Regression
2. Decision Tree
3. Random Forest

These models were selected to examine how different classification approaches respond to increasing levels of missing input data.

## Missing Data Experiment

Artificial missing values were introduced into the training features at six levels: 0%, 5%, 10%, 20%, 30%, and 40%. The test set remained unchanged and complete throughout the experiments.

Five random seeds (10, 20, 30, 40, and 42) were used to generate different missing-data patterns at each non-zero missing-data level. The same generated training-data pattern was used for all three models within each seed and missing-data level, supporting a consistent comparison.

The experiment comprised 90 model runs: six missing-data levels, five seeds, and three models.

## Missing Data Imputation

Median imputation was used in the repeated missing-data experiment. Each model's imputation procedure was fitted using the training data only, preventing information from the test set from influencing the imputation values.

Logistic Regression was evaluated without feature standardization in the final experiment. Decision Tree and Random Forest were also evaluated using median imputation, without feature standardization.

A separate mean-versus-median imputation experiment was conducted previously. Its results are considered separately from the repeated experiment reported here.

## Evaluation Metrics

Model performance was evaluated using accuracy and F1 score. For each combination of missing-data level and model, the mean and standard deviation of both metrics were calculated across the five random-seed runs.

The results were compared across missing-data levels and models to assess changes in predictive performance as the proportion of missing training data increased.
