Impact of Missing Data on Machine Learning Prediction Performance


Abstract

Missing data is a common problem in real-world datasets and can affect the performance of machine learning models. This study investigates how different levels of missing data affect the prediction performance of basic machine learning models.

The Banknote Authentication dataset was used in this study. Missing values were artificially introduced into the training data at six levels: 0%, 5%, 10%, 20%, 30%, and 40%. Three machine learning models were evaluated: Logistic Regression, Decision Tree, and Random Forest. Multiple random seeds were used to repeat the missing-data experiments. Model performance was evaluated using accuracy and F1 score. Mean and median imputation were also compared as simple missing-data preprocessing methods.

The results showed that increasing missing data generally reduced model performance. Logistic Regression showed the largest decrease in mean accuracy, from 98.55% at 0% missing data to 90.47% at 40% missing data. Decision Tree decreased from 99.27% to 93.89%, while Random Forest decreased from 99.64% to 97.96%. In this experimental setup, Random Forest showed the smallest overall performance decrease. The comparison of mean and median imputation showed that their differences were generally small at lower missing-data levels, while median imputation produced higher mean accuracy at 40% missing data for all three models.

Overall, the findings indicate that increasing missing data can negatively affect machine learning prediction performance and that different models can respond differently to missing data.


1. Introduction

Machine learning is widely used for prediction and classification tasks in many different areas. Machine learning models learn patterns from available data and use these patterns to make predictions. The quality of the data can therefore have an important effect on model performance.

One common problem in real-world datasets is missing data. Missing values can occur because of incomplete records, data entry problems, system errors, or other reasons. When important values are missing, machine learning models may not be able to use all the available information effectively. Therefore, missing data needs to be considered when developing and evaluating machine learning models.

Previous research has investigated the effect of missing data on machine learning prediction. Marlin (2008) studied learning, inference, and prediction with missing data and investigated different approaches for handling missing information. Radišić, Seljan, and Dunđer (2023) examined the effect of missing values and different imputation methods on several machine learning algorithms. Their results showed that the effect of missing-data treatment can differ between machine learning models.

Although previous studies have investigated missing data and different methods for handling it, this study focuses on a controlled experiment using different levels of missing data under the same experimental setup. The study introduces different percentages of missing values into the training data and measures how the performance of basic machine learning models changes.

The main objective of this study is to investigate how different levels of missing data affect the prediction performance of Logistic Regression, Decision Tree, and Random Forest models. The study also compares mean and median imputation to examine whether simple preprocessing methods can reduce the effect of missing data on model performance.


2. Literature Review

Previous research has investigated the effect of missing data on machine learning prediction and classification.

Marlin (2008) studied learning, inference, and prediction when data contains missing values. The work considered classification with missing features and collaborative prediction with non-random missing data. Different approaches were investigated, including imputation and models that explicitly considered the missing-data process. The study used Yahoo! Music LaunchCast rating data and synthetic data based on the Jester dataset. The work showed that considering the missing-data mechanism can improve prediction performance in some settings.

Radišić, Seljan, and Dunđer (2023) investigated the impact of missing values and missing-data replacement methods on machine learning algorithms. Their study used data from 309 students and compared four versions of the dataset: the original dataset with missing values, arithmetic mean imputation, median imputation, and geometric mean imputation. The study evaluated K-Nearest Neighbors, Naïve Bayes, Random Forest, and Probabilistic Neural Network models using accuracy, F1 score, and confusion matrices. The results showed that the effect of missing-data treatment differed between machine learning algorithms.

These studies show that missing data and its treatment can affect machine learning prediction performance. However, the present study focuses on a controlled experiment in which different percentages of missing data are introduced into the same dataset and the performance of basic machine learning models is measured under the same experimental setup. The study also compares mean and median imputation across different levels of missing data.

Based on this research direction, the present study investigates how model performance changes as the amount of missing data increases and whether simple imputation methods can reduce the effect of missing data on model performance.


3. Methodology

3.1 Dataset

The Banknote Authentication dataset was used for this study. The dataset contains 1,372 observations and four numerical input features: variance, skewness, curtosis, and entropy. The target variable is the class of the banknote, which represents whether the banknote is genuine or forged.

3.2 Data Preparation

The dataset was checked before the experiments to understand its structure, data types, missing values, and class distribution. The original dataset did not contain missing values. The four numerical features were used as input variables, while the class variable was used as the target variable.

The dataset was divided into training and testing sets using an 80:20 split. Stratified splitting was used to maintain the class distribution in both sets. A fixed random state of 42 was used for the train-test split.

3.3 Machine Learning Models

Three basic machine learning models were selected for the experiments:

1. Logistic Regression
2. Decision Tree
3. Random Forest

These models were selected to compare the effect of missing data across different types of machine learning models.

3.4 Missing Data Experiment

Missing values were artificially introduced into the training data at six different levels: 0%, 5%, 10%, 20%, 30%, and 40%.

The test data was kept clean during the experiments. This allowed the models to be evaluated on the same complete test data at each missing-data level.

For each missing-data level, multiple random seeds were used to generate different missing-data patterns. Five random seeds were used: 10, 20, 30, 40, and 42.

3.5 Missing Data Imputation

Median imputation was used in the repeated missing-data experiment. The imputer was fitted only on the training data and then applied to the training data containing missing values. The clean test data was not used to calculate the imputation values.

A separate experiment was also conducted to compare mean and median imputation at each missing-data level.

3.6 Evaluation

Model performance was evaluated using accuracy and F1 score. Mean performance and standard deviation were calculated across the five missing-data random seeds.

The results were compared across different missing-data levels and machine learning models to determine how increasing missing data affected prediction performance.


4. Results

The repeated experiments showed that increasing missing data generally reduced the performance of the machine learning models. However, the amount of performance reduction was different for each model.

5. Discussion

The results generally support the main hypothesis that increasing missing data can reduce machine learning prediction performance. However, the effect was different for the three models used in this study.

Logistic Regression showed the largest decrease in performance as missing data increased. Decision Tree also showed a noticeable decrease, while Random Forest showed the smallest overall decrease in this experimental setup.

These results suggest that different machine learning models may have different levels of sensitivity to missing data. Random Forest maintained relatively high performance even at higher missing-data levels, while Logistic Regression experienced a larger decrease.

The repeated experiments were important because different random missing-data patterns produced some variation in model performance. Therefore, using only one missing-data pattern could give a less reliable view of the effect.

The comparison of mean and median imputation showed that neither method was consistently better at every missing-data level. Their differences were generally small at lower missing-data levels, while median imputation performed better at 40% missing data for all three models.

The findings should be interpreted within the limitations of the study. The experiments used one dataset, three machine learning models, artificially generated random missing values, and two simple imputation methods. Therefore, the results cannot be generalized to all datasets or real-world missing-data situations.


6. Limitations

This study has several limitations.

First, the study uses only one dataset, the Banknote Authentication dataset. Therefore, the findings may not represent the behavior of machine learning models on other types of datasets.

Second, missing values were introduced artificially into the training data. The missing values were generated randomly at different percentages. Real-world missing data may occur through different mechanisms and may not be completely random.

Third, the study compares only three basic machine learning models: Logistic Regression, Decision Tree, and Random Forest. Other machine learning algorithms may respond differently to missing data.

Fourth, the study uses a fixed 80:20 train-test split. Although multiple missing-data seeds were used, different train-test splits may produce different results.

Fifth, only mean and median imputation were compared. Other missing-data handling methods, such as KNN imputation, iterative imputation, or multiple imputation, were not investigated.

Finally, the study evaluates the models using one dataset and a controlled experimental setup. Therefore, the results should be interpreted as findings from this experimental setting rather than general conclusions about all machine learning applications.


7. Conclusion

This study investigated how different levels of missing data affect the performance of basic machine learning models.

The experiments were conducted using the Banknote Authentication dataset and three machine learning models: Logistic Regression, Decision Tree, and Random Forest. Missing values were artificially introduced at different levels from 0% to 40%. The models were evaluated using accuracy and F1 score.

The results showed that increasing missing data generally reduced model performance. Logistic Regression showed the largest decrease in mean accuracy, from 98.55% at 0% missing data to 90.47% at 40% missing data. Decision Tree decreased from 99.27% to 93.89%, while Random Forest decreased from 99.64% to 97.96%.

The results also showed that different machine learning models responded differently to missing data. In this experimental setup, Random Forest showed the smallest overall performance decrease.

The study also compared mean and median imputation. The differences between the two methods were generally small at lower missing-data levels. At 40% missing data, median imputation produced higher mean accuracy for all three models.

Overall, the findings indicate that missing data can negatively affect machine learning prediction performance and that the effect can differ between machine learning models. Simple preprocessing methods such as mean and median imputation can help models handle missing values, but their effectiveness may depend on the model and the amount of missing data.


8. Future Work

Future studies can extend this work in several directions.

First, the experiments can be repeated using multiple datasets from different domains to determine whether similar patterns are observed.

Second, future work can investigate different missing-data mechanisms instead of only randomly introducing missing values. For example, missing data can be generated under different assumptions about why values are missing.

Third, more machine learning models can be compared, including K-Nearest Neighbors, Support Vector Machines, and other classification algorithms.

Fourth, additional missing-data handling methods can be evaluated. These may include KNN imputation, iterative imputation, and multiple imputation.

Finally, future experiments can use additional evaluation metrics and different train-test splits or cross-validation to provide a more extensive evaluation of model performance.
