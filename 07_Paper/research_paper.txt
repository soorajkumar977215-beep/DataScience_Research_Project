# Impact of Missing Data on Machine Learning Prediction Performance

## Abstract

Missing data is a common problem in real-world datasets and can affect the performance of machine learning models. This study investigates how different levels of missing data affect the prediction performance of three machine learning models.

The Banknote Authentication dataset, containing 1,372 observations and four numerical input features, was used in this study (Lohweg, 2013). Missing values were artificially introduced into the training features at six levels: 0%, 5%, 10%, 20%, 30%, and 40%. Three machine learning models were evaluated: Logistic Regression, Decision Tree, and Random Forest. Five random seeds were used to generate different missing-data patterns at each level. Median imputation was applied in the main repeated experiment, and model performance was evaluated using accuracy and F1-score. The experiment consisted of 90 model runs across the six missing-data levels, five seeds, and three models.

The results showed that increasing missing data generally reduced model performance. Logistic Regression showed the largest decrease in mean accuracy, from 98.55% at 0% missing data to 90.84% at 40% missing data. Decision Tree decreased from 99.27% to 95.78%, while Random Forest decreased from 99.64% to 98.11%. The corresponding decreases were 7.71, 3.49, and 1.53 percentage points, respectively. Random Forest showed the smallest overall decrease in mean accuracy under the tested conditions.

Overall, the findings indicate that the effect of increasing missing data differs across machine learning models. However, the results are limited to the selected dataset, models, missing-data generation procedure, and imputation method.

## 1. Introduction

Machine learning is widely used for prediction and classification tasks in many different areas. Machine learning models learn patterns from available data and use these patterns to make predictions. The quality of the data can therefore have an important effect on model performance.

One common problem in real-world datasets is missing data. Missing values can occur because of incomplete records, data-entry problems, system errors, or other reasons. When important values are missing, machine learning models may not be able to use all available information effectively. Therefore, missing data needs to be considered when developing and evaluating machine learning models.

Previous research has investigated the effect of missing data on machine learning prediction. Marlin (2008) studied learning, inference, and prediction with missing data and investigated different approaches for handling missing information. Radišić, Seljan, and Dunđer (2023) examined the effect of missing values and different imputation methods on several machine learning algorithms. Their work highlights that the effects of missing-data treatment can differ between machine learning models.

Although previous studies have investigated missing data and methods for handling it, this study focuses on a controlled experiment using different levels of missing data under a consistent experimental setup. Different percentages of missing values are introduced into the training features, and the performance of three machine learning models is evaluated on a complete test set.

The main objective of this study is to investigate how different levels of missing data affect the prediction performance of Logistic Regression, Decision Tree, and Random Forest models. The study uses median imputation in its main repeated experiment and evaluates changes in accuracy and F1-score as the proportion of missing data increases.

## 2. Literature Review

Previous research has investigated the effect of missing data and missing-data handling methods on machine learning prediction and classification.

Marlin (2008) studied learning, inference, and prediction in the presence of missing data. The thesis examined classification with missing features and collaborative prediction with non-random missing data. Different approaches were investigated, including imputation and models that explicitly considered the missing-data process. The work included experiments using Yahoo! Music LaunchCast rating data and synthetic data based on the Jester dataset. The findings demonstrated that accounting for the missing-data mechanism can improve prediction performance in certain settings.

Radišić, Seljan, and Dunđer (2023) investigated the impact of missing values and missing-data replacement methods on machine learning algorithms. Their study used data from 309 students and compared four dataset versions: the original dataset containing missing values, arithmetic mean imputation, median imputation, and geometric mean imputation. The researchers evaluated K-Nearest Neighbors, Naïve Bayes, Random Forest, and Probabilistic Neural Network models using accuracy, F1-score, and confusion matrices. Their work highlighted that the effects of missing-data treatment can differ across machine learning algorithms.

These studies demonstrate that missing data and the methods used to handle it can influence machine learning prediction performance. However, the present study focuses on a controlled experiment using the Banknote Authentication dataset. Different percentages of missing values are introduced into the training features, and the performance of Logistic Regression, Decision Tree, and Random Forest models is evaluated under a consistent experimental setup.

The main repeated experiment uses median imputation to investigate how model performance changes as the proportion of missing data increases. A separate comparison of mean and median imputation is outside the scope of the main repeated experiment and is not reported as a confirmed finding in this study because its underlying results require independent verification. This distinction allows the present study to focus on the relationship between increasing missing-data levels and model performance.

## 3. Methodology

### 3.1 Dataset

The Banknote Authentication dataset was used for this study (Lohweg, 2013). The dataset contains 1,372 observations and four numerical input features: variance, skewness, curtosis, and entropy. The target variable represents whether a banknote is genuine or forged.

### 3.2 Data Preparation

The dataset was examined to understand its structure, data types, original missing values, and class distribution. The original dataset did not contain missing values. The four numerical features were used as input variables, while the class variable was used as the target variable.

The dataset was divided into training and testing sets using an 80:20 split. Stratified splitting was used to maintain the class distribution in both sets. A fixed random state of 42 was used for the train-test split, resulting in 1,097 training observations and 275 testing observations.

### 3.3 Machine Learning Models

Three machine learning models were selected for the experiments:

1. Logistic Regression
2. Decision Tree
3. Random Forest

These models were selected to compare the effect of increasing missing data across different classification algorithms.

### 3.4 Missing Data Experiment

Missing values were artificially introduced into the training features at six different levels: 0%, 5%, 10%, 20%, 30%, and 40%.

The test data was kept complete throughout the main repeated experiment. This allowed the models to be evaluated on the same complete test set at each missing-data level.

For each missing-data level, five random seeds were used to generate different missing-data patterns: 10, 20, 30, 40, and 42. The six missing-data levels, five seeds, and three models resulted in 90 model runs.

### 3.5 Missing Data Imputation

Median imputation was used in the main repeated missing-data experiment. The imputer was fitted using the training data only and then applied to the training features containing missing values. The test data was not used to calculate the imputation values.

A separate mean-versus-median imputation experiment was also conducted previously. Its results are considered separately from the main repeated experiment and are not reported as confirmed findings here because the underlying results require independent verification.

### 3.6 Evaluation Metrics

Model performance was evaluated using accuracy and F1-score. Mean performance and standard deviation were calculated across the five missing-data random seeds for each missing-data level and model.

Accuracy was used to measure the proportion of correct predictions. F1-score was used to evaluate the balance between precision and recall. The results were compared across missing-data levels and models to examine changes in prediction performance.

## 4. Results

The repeated experiments showed that increasing missing data generally reduced the performance of the machine learning models. However, the magnitude of the reduction varied across models.

## 5. Discussion

The results generally support the hypothesis that increasing missing data can reduce machine learning prediction performance. However, the magnitude of the effect differed across the three models evaluated in this study.

Logistic Regression showed the largest decrease in accuracy and F1-score as missing data increased. Decision Tree also showed a noticeable decline, while Random Forest maintained comparatively high performance throughout the tested missing-data levels.

These results suggest that the models differed in their sensitivity to missing data under the experimental conditions. Random Forest exhibited the smallest reduction in mean accuracy, while Logistic Regression was more affected by increasing missingness. However, these findings do not establish that Random Forest will always be more robust on other datasets or under different missing-data mechanisms.

The repeated experiments were important because different random missing-data patterns produced variation in model performance. Evaluating five seeds provided information about variability across these patterns. However, because the train-test split remained fixed, this variation does not represent variability across different train-test splits.

The results should be interpreted within the limitations of the study. Only one dataset, three machine learning models, one missing-data generation procedure, and median imputation were used in the main repeated experiment. Further studies are needed to determine whether similar patterns occur with other datasets, models, and imputation methods.

## 6. Limitations

This study has several limitations that should be considered when interpreting the results.

First, the study uses only the Banknote Authentication dataset, which contains four numerical input features. The findings may not generalize to datasets with different sizes, feature types, class distributions, or levels of complexity.

Second, missing values were artificially introduced into the training features using random masks at predefined percentages. This procedure represents a controlled missing-data scenario but does not capture all real-world missing-data mechanisms. In particular, missingness related to observed or unobserved data characteristics was not investigated.

Third, the study evaluates only three classification algorithms: Logistic Regression, Decision Tree, and Random Forest. Other algorithms, including methods specifically designed to handle missing values, may respond differently to increasing missingness.

Fourth, the experiments use a fixed stratified 80:20 train-test split. Although five random seeds were used to generate different missing-data patterns, the train-test split itself was not repeated. Consequently, the reported variability reflects changes across missing-data patterns rather than variability across different train-test splits.

Fifth, median imputation was used in the repeated missing-data experiment. The main repeated experiment therefore does not establish whether median imputation is superior to other imputation strategies. A separate mean-versus-median comparison must be interpreted independently using its verified results. More advanced approaches, such as K-nearest-neighbor imputation, iterative imputation, and multiple imputation, were not evaluated in the repeated experiment.

Finally, the test set was kept complete while missing values were introduced only into the training features. The findings therefore describe model performance under this specific evaluation setup and may not reflect scenarios in which missing values are also present in the test data.

## 7. Conclusion

This study investigated how different levels of missing data affect the performance of Logistic Regression, Decision Tree, and Random Forest models using the Banknote Authentication dataset.

Missing values were artificially introduced into the training features at six levels, from 0% to 40%. The main repeated experiment used median imputation, and model performance was evaluated using accuracy and F1-score across five missing-data random seeds.

The results showed that increasing missing data generally reduced model performance. Logistic Regression showed the largest decrease in mean accuracy, from 98.55% at 0% missing data to 90.84% at 40% missing data. Decision Tree decreased from 99.27% to 95.78%, while Random Forest decreased from 99.64% to 98.11%.

The corresponding decreases in mean accuracy were 7.71 percentage points for Logistic Regression, 3.49 percentage points for Decision Tree, and 1.53 percentage points for Random Forest. The F1-score results also showed a decline in performance as missing data increased.

Overall, the findings demonstrate that the effect of missing data can differ across machine learning models. Random Forest maintained comparatively high performance in this experimental setup, while Logistic Regression showed a larger reduction. These conclusions are limited to the selected dataset, models, missing-data generation procedure, and imputation method. Future research should evaluate additional datasets, missing-data mechanisms, algorithms, and imputation strategies to assess the generalizability of these findings.

## 8. Future Work

Future studies can extend this work in several directions.

First, the experiments can be repeated using multiple datasets from different domains to determine whether similar patterns are observed across different data characteristics, dataset sizes, and classification tasks.

Second, future work can investigate different missing-data mechanisms rather than introducing missing values randomly. For example, experiments could consider Missing Completely at Random (MCAR), Missing at Random (MAR), and Missing Not at Random (MNAR) scenarios to evaluate how different missingness assumptions affect model performance.

Third, additional machine learning models can be evaluated, including K-Nearest Neighbors, Support Vector Machines, and other classification algorithms. This would help determine whether the observed differences in robustness to missing data extend to a wider range of models.

Fourth, additional missing-data handling methods can be investigated. These may include KNN imputation, iterative imputation, and multiple imputation. Future experiments could also compare mean and median imputation using repeated trials and consistent evaluation procedures.

Finally, future experiments can use additional evaluation metrics, repeated train-test splits, and cross-validation to provide a more comprehensive assessment of model performance and variability. These extensions could help establish whether the findings remain consistent under different experimental conditions.
